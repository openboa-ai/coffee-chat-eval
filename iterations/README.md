# Iterations

Each iteration is one attributable change to a Product Skill, evaluator, or
qualified Judge with the other comparison surfaces frozen. Preserve the exact
Product and Bench revisions, clean input materialization, with-skill and
without-skill outputs, timing, grading, traces, and human feedback.

An iteration is evidence, not a release or a benchmark activation. Missing,
failed, unavailable, and unmeasured results remain explicit.
