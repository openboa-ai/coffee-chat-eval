# coffee-chat-eval

Controlled evaluation runs and grading evidence for Coffee Chat.

`coffee-chat-eval` owns controlled evaluation execution, comparison traces, timing, grading runs, and measured evidence for the [Coffee Chat](https://github.com/openboa-ai/coffee-chat) repository family.

## Status

This repository currently holds the verified CI and security baseline while evaluation harnesses and run records are prepared. CI checks workflow syntax, whitespace, and secrets; these checks do not validate product behavior, and no deployment credentials or release pipeline are configured here.
